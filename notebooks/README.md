# Notebooks

`01_exploratory_analysis.ipynb` is the exploratory notebook this pipeline grew out of:
raster alignment checks, EDA, the first model comparison and the original deployment
sketch.

It is kept for provenance only. **The scripted pipeline in `src/floodrisk/` is the
authoritative implementation** — the capstone brief rules out notebook-only submissions,
and the notebook's results predate several decisions made in the pipeline (explicit
exclusion of permanent water from the non-flood class, leakage-safe stacking, and the
model-selection rule). Where the two disagree, the pipeline is correct.

Reproduce results with `python scripts/run_pipeline.py`, not by running this notebook.

## A note on outputs

Cell outputs have been stripped from the notebook. Committed notebook outputs bloat a
repository and go stale the moment the code changes; the authoritative results live in
`outputs/` and `models/model_card.json`, regenerated by the pipeline.
